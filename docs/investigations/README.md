# Technical Investigations & Bug Reports

This directory contains detailed records of technical investigations, bug fixes, and experiments performed on the StatsChat codebase.

## Purpose
The documents in this folder serve as a knowledge base for:
- Diagnosing complex issues.
- Documenting the steps taken to reproduce bugs (experiments).
- Explaining the root cause of issues.
- Detailing the solutions applied.

## When to add a document here
Create a new investigation document when:
1. You encounter a bug that requires non-trivial debugging or experimentation to solve.
2. You run specific experiments to validate a hypothesis about the system's behavior.
3. You implement a fix for a significant issue and want to preserve the context for future maintainers.

## Format
Documents should generally include:
- **Problem Description:** What went wrong?
- **Experiment/Reproduction:** How did we verify the issue?
- **Root Cause:** What was the underlying technical reason?
- **Fix:** What code was changed?
- **Verification:** How do we know it works now?
